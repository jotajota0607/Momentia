# Módulos JavaScript (ES6)

Módulos desacoplados que encapsulan funcionalidad específica:
- `navigation.js` (Menú responsive, estado de scroll)
- `modal.js` (Ventanas emergentes accesibles)
- `form-validator.js` (Validación en cliente accesible y dinámica)
- `analytics.js` (Eventos y métricas de conversión)
